# 隐私与元数据

## relay 看不到什么

提示词、代码、模型回复、会话标题、定时任务内容、工具参数和权限卡内容都在手机与电脑之间端到端加密。relay 不持有设备私钥，不能解密这些内容。

## relay 能看到什么

- channelId、deviceId、host/device 角色；
- 连接时间、断线重连、帧大小、流量和限流事件；
- 离线密文帧的 TTL 队列（仅内存）。

这些元数据可能推断“何时在使用编程工具”。有更高隐私要求时请自托管 relay 或使用 Tailscale。

## 密钥分层

- 设备 E2E 私钥：只在手机/电脑上，relay 永远不需要。
- relay 访问密钥：可选共享准入凭证，只用于 `POST /v1/tickets` 的 Authorization 头。
- 单次 ticket：短期、绑定 channel/role/device，用于 WS URL；不记录到应用日志。

访问密钥泄露不等于会话内容泄露，但会让第三方使用 relay 资源，应立即轮换。设备吊销在桌面设备列表中独立执行。

## 日志与保留

应用不记录业务帧、长期访问密钥、ticket 或 WS 查询字符串。健康端点只返回 `{ok,version}`。生产反代访问日志也应关闭或脱敏查询字符串。

## 当前密码学边界

当前使用长期设备密钥的 NaCl box 与防重放序号，**不宣称前向保密**。手机端私钥存 IndexedDB，PWA XSS 是该存储的主要风险；请只使用可信 PWA origin、严格 CSP 和设备吊销。

离线队列是内存 best-effort 缓存，不是长期历史库。relay 重启后，会话恢复依赖桌面权威快照、历史和输出补拉。
